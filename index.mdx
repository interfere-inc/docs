Interfere collects telemetry from your apps, groups related errors into problems, and investigates their causes. Each problem brings together the affected users, releases, sessions, and supporting evidence.

## Set up an app

Create a [surface](/product/surfaces) for each app you deploy separately. Install its SDK, set the surface keys, and connect your code repository and deployment platform. The [quickstart](/quickstart) walks through setup and verification.

## Investigate a problem

Open the [Inbox](/product/inbox) to review problems. Filter by environment or surface, check impact, and open a problem to read the investigation. Use its [traces and session replays](/product/problems) to inspect what happened. Assign the work, add context, and subscribe to updates.
