Use this connection for a GitHub Enterprise Cloud organization on a `*.ghe.com` host. If your enterprise uses `github.com`, use the [GitHub connection](/integrations/github).

## Connect your enterprise

Open [Enterprise Cloud settings](https://interfere.com/~/*/settings/integrations/ghe_cloud) and enter your host, such as `acme.ghe.com`. Complete app registration, then install the dedicated GitHub App and select the repositories it can read.

Link each repository to its [surface](/product/surfaces). For a monorepo, choose the app's subdirectory.

## Check release context

After deploying with the SDK build plugin, open the surface's [Releases](/product/surfaces/releases) and check the commit. See [SDK release configuration](/sdk/releases) for build setup.
