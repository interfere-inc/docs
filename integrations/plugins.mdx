The Interfere plugin connects your editor to the [MCP](/integrations/mcp) and adds a skill for investigating production problems. You need an Interfere account with access to the workspace you want to inspect.

## Claude Code

Install from [Interfere's Claude plugin marketplace](https://github.com/interfere-inc/plugins/blob/main/.claude-plugin/marketplace.json) by running these commands inside Claude Code:

```text
/plugin marketplace add interfere-inc/plugins
/plugin install interfere@interfere-plugin-marketplace
```

Open `/mcp`, connect your Interfere account, and select your workspace.

## Cursor

Install the plugin from the [Interfere plugin repository](https://github.com/interfere-inc/plugins):

```bash
git clone https://github.com/interfere-inc/plugins.git interfere-plugins
mkdir -p ~/.cursor/plugins/local
cp -R interfere-plugins/plugins/interfere ~/.cursor/plugins/local/interfere
```

Reload Cursor and open **Customize** to connect the Interfere MCP server. Managed installations may require your administrator to allow local plugin imports.

## Investigate

Give the agent a problem link or a time range and ask it to investigate. For example:

```text
Investigate recent checkout errors in my Interfere workspace. Identify the
release, affected sessions, and evidence supporting the likely cause.
```

Include your workspace and surface if you have more than one. Ask for links to the problem, affected sessions, and supporting traces so you can inspect the evidence in Interfere.

## Connection permissions

The plugin uses `https://mcp.interfere.com/mcp`. This connection permits reads and writes within your existing permissions. For enforced read-only access, configure the [read-only MCP endpoint](/integrations/mcp) directly and disable the plugin's write-enabled connection in your client.

Reconnect through your client if authentication expires, or check your workspace permissions if access is denied. Keep passwords and tokens out of chat and plugin files.
