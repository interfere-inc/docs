Workspace owners and administrators can open [Settings → Audit log](https://interfere.com/~/*/settings/audit-log) to review administrative events.

## Find an event

Filter by event type, user, or time window. Events appear in a chronological feed with pagination. Use the filters to narrow a search before opening individual records.

## Inspect details

Open an event to see its author, email, affected resource, source, and event ID. The source distinguishes dashboard actions from API actions. Event metadata provides details specific to the change.

Copy an event ID when reporting an unexpected change to support. The [Activity feed](/product/activity) covers product and team updates; the audit log records administrative actions.
