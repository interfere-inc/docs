Workspace owners and administrators can review administrative changes in [Audit log](https://interfere.com/~/*/settings/audit-log).

## Find a change

Filter by event type, user, or time window. For example, if workspace access changed yesterday, narrow the time window and look for the corresponding security setting change.

Open an event to inspect its author, affected resource, source, and metadata. The source distinguishes dashboard actions from API actions. Metadata describes the specific change.

Copy the event ID when asking support to investigate an unexpected change.

For problem updates and team activity, use [Activity](/product/activity).
