Data residency determines whether your workspace's data is restricted to a geographic region. Check **Data residency** in [Workspace settings](https://interfere.com/~/*/settings/workspace) to see your workspace's policy.

<Info>
  Regional residency is not yet available. All workspaces currently use Unrestricted; Enterprise
  alone does not enable a regional guarantee.
</Info>

## Unrestricted

All workspaces currently use **Unrestricted** residency, which lets Interfere store and process data in different regions as needed. Those locations may change, so neither Pro nor Enterprise currently guarantees that data stays in the United States or European Union.

## Regional residency <EnterpriseBadge />

US and EU region locking is planned for Enterprise workspaces, but you cannot select a region during setup or in workspace settings yet.

If your team needs regional residency, contact [support@interfere.com](mailto:support@interfere.com) with the region and data you need covered so we can confirm availability and scope before you send data that must stay there.

## Storage and processing

Residency requirements can cover storage, processing, or both. In Interfere, that includes telemetry, session replay, source maps, and investigation data, including AI processing; none currently has a geographic restriction under the unrestricted policy.

The region in an API key determines request routing, not residency. Keep using the keys and SDK configuration provided for your workspace, as changing a key prefix won't move data or enable region locking.

## Related settings

[Network access](/product/network-access) controls which networks can reach your workspace. It does not control where Interfere stores or processes data. For security documentation and reports, see [Trust Center](/product/compliance).
