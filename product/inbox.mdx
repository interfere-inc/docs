The [Inbox](https://interfere.com/~/*) lists problems detected from your app's events. Related occurrences are grouped so you can review their impact and investigation together.

![Inbox board showing problems grouped by status](/images/inbox.png)

## Choose a view

Use the board to group problems by status, or the list for a compact view. Open **Display** to sort by priority, affected users, first detected, or last detected, in ascending or descending order. Failed investigations can be shown or hidden.

## Filter problems

Filter by environment to focus on production, staging, or another deployment environment. Combine filters such as surface, assignee, priority, and status to narrow the list. A problem ID filter lets you return to a specific set of problems.

Press <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>F</kbd> to clear active filters. On macOS, use <kbd>Option</kbd> for Alt.

## Select and act in bulk

Select several problems to assign them, change their priority, or subscribe to updates in one action. These actions follow your workspace permissions.

| Shortcut           | Action                                          |
| ------------------ | ----------------------------------------------- |
| Arrow keys         | Move through problems.                          |
| Shift + arrow keys | Extend or reduce the selection.                 |
| ⌘ A or Ctrl A      | Select all filtered problems.                   |
| Escape             | Clear the selection.                            |
| A                  | Assign selected problems.                       |
| P                  | Set priority for selected problems.             |
| S                  | Change your subscription for selected problems. |

Text fields keep their normal editing shortcuts.

## Follow an investigation

Open a problem to read its timeline, inspect evidence, and review sessions. An investigation can still be in progress or fail before it produces an explanation. See [problem statuses](/concepts#statuses) and the [problem view](/product/problems).
