Open [Knowledge](https://interfere.com/~/*/knowledge) to review your workspace's data sources. This inventory helps you check which sources are available when an investigation needs more context.

## Find a data source

Search by name, then filter by **Source** or **Availability** to narrow the list. Viewing this inventory requires permission to read integration settings.

## Add a source

Select **Add data source** to open **Settings → Connections**. Follow the guide for your provider:

- [GitHub](/integrations/github) connects repositories for code context.
- [Vercel](/integrations/vercel) connects deployment projects.
- [Cloudflare Workers](/integrations/cloudflare-workers) connects Worker telemetry.

Members with permission to manage integrations can also select **Set up OpenTelemetry** from Knowledge. Follow [OpenTelemetry ingestion](/sdk/otel-ingestion) to create a telemetry key and configure your Collector or exporter.
