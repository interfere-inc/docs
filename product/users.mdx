Open [Users](https://interfere.com/~/*/users) to find someone using your app. Their profile brings together user traits, recent activity, surfaces they have used, and active problems affecting them.

## Find an affected user

Open a profile, review its active problems, and select a problem to read the investigation. Resolved problems no longer appear in the active-problems panel.

If you are investigating a customer report, open a session from the profile and use its event timeline to find the reported action. See [Session replay](/product/session-replay).

## Identify signed-in users

Sessions start anonymously. Call `identity.set()` after your app loads the signed-in user to attach a stable user ID, name, email, and other traits. Follow [Identify users](/sdk/identity) for the React integration.

Use a stable internal ID for `identifier` so changes to someone's email do not change their identity.

For account-wide impact, open the associated [company](/product/companies).
