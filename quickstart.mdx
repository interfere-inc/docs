Create a workspace, install the SDK in your app, and check that Interfere receives events.

## Create a workspace

Open [setup](https://interfere.com/onboarding). Choose a workspace name, URL slug, company email domain, and data residency region.

The slug identifies your workspace in links and API requests. For `interfere.com/~/acme`, it is `acme`.

Choose **US** or **EU** for data residency before creating the workspace. This choice applies to the workspace and its keys. Use your team's email domain so colleagues can join through your [workspace domain settings](/product/settings#workspace-domains).

## Add your app

Create a surface for the app you want to monitor. Give separately deployed apps their own surfaces, such as a storefront and its backend API.

Choose the framework and copy the surface's public key. The SDK uses it to send telemetry. Copy the secret API key to your build environment for release registration and source maps.

## Connect your code and deployment

Connect [GitHub](/integrations/github) and select the repository for your surface. This gives investigations access to the code behind an error.

Connect [Vercel](/integrations/vercel) or [Cloudflare Workers](/integrations/cloudflare-workers) if you deploy there, then map the project or Worker to your surface. For other hosts, the SDK build plugins publish [release metadata and source maps](/sdk/releases).

## Verify events

Build and deploy the app with its public key and an environment label such as `staging`. Run the test capture in your SDK guide, then open the surface in [Surfaces](https://interfere.com/~/*/surfaces).

The event chart should show incoming traffic. Setup's **Events** step completes when the first event arrives. If the chart stays empty, follow [No events arriving](/sdk/troubleshooting).

Finish the remaining setup steps, including selecting a plan. You can then open the [Inbox](/product/inbox) and inspect problems as Interfere detects and investigates them. Receiving an event and completing an investigation are separate steps.
