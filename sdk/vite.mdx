Use `@interfere/vite` with Vite 5 or later, React 19 or later, and Node.js 20 or later. For a server-rendered Start app, follow [TanStack Start](/sdk/tanstack-start).

## Install

```bash
npm install @interfere/vite @interfere/react
```

## Set your keys

Copy the keys from your [surface](/product/surfaces) into the build environment:

```env
VITE_INTERFERE_PUBLIC_KEY=YOUR_SURFACE_PUBLIC_KEY
INTERFERE_API_KEY=YOUR_SURFACE_SECRET_KEY
INTERFERE_ENVIRONMENT=staging
```

Use `production` for production builds. Only the public key gets a `VITE_` prefix. Prefixing the secret key would expose it in the browser bundle.

## Add the build plugin

Enable source maps and add `interfere()` to your Vite plugins. Keep your other plugins and app configuration.

```ts vite.config.ts
import { interfere } from "@interfere/vite/plugin";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  build: { sourcemap: true },
  plugins: [react(), interfere()],
});
```

The plugin uploads source maps and registers the build's release. See [Releases and source maps](/sdk/releases) for custom build environments.

## Initialize before rendering

Call `init()` in your browser entry point, before React renders.

```tsx src/main.tsx
import { init } from "@interfere/vite/init";
import { InterfereProvider } from "@interfere/vite/provider";
import { createRoot } from "react-dom/client";
import { App } from "./app";

init();

createRoot(document.getElementById("root")!).render(
  <InterfereProvider>
    <App />
  </InterfereProvider>,
);
```

Configure [consent](/sdk/consent) and [replay masking](/sdk/replay-privacy) on the provider before deploying capture to customers.

## Verify capture

Add a temporary button to a page in your staging app:

```tsx src/capture-test.tsx
import { capture } from "@interfere/vite/init";

export function CaptureTest() {
  return (
    <button onClick={() => capture(new Error("Interfere setup test"))}>Send test error</button>
  );
}
```

Build and deploy, then select **Send test error**. Open the surface's event chart to confirm traffic arrives. Remove the button after verification. If the chart stays empty, follow [No events arriving](/sdk/troubleshooting).

## Capture only production builds

The Vite browser SDK runs whenever it is initialized. To disable it during local development, use:

```ts
init({ enabled: import.meta.env.PROD });
```
