---
title: "Vite"
description: "Capture errors and sessions in a React app built with Vite."
---

`@interfere/vite` captures browser errors and sessions from your React app. Its build plugin connects those events to a release and uploads source maps for readable stack traces.

Use SDK 13.0.x with Vite 8.2.4 or later within Vite 8 and React 19. For a server-rendered Start app, follow [TanStack Start](/sdk/tanstack-start).

## Setup

<Steps>
  <Step title="Install the packages">

<CodeGroup>

```bash npm
npm install @interfere/vite @interfere/react
```

```bash pnpm
pnpm add @interfere/vite @interfere/react
```

```bash Yarn
yarn add @interfere/vite @interfere/react
```

```bash Bun
bun add @interfere/vite @interfere/react
```

</CodeGroup>

  </Step>
  <Step title="Set your workspace secret">

Create a workspace secret in [Developer settings](https://interfere.com/~/*/settings/developer) with **Source maps** (`release:write`) for the build. For server telemetry, also grant **Send telemetry** (`org:telemetry:write`) and provide the secret to the server runtime.

```env
INTERFERE_API_KEY=YOUR_WORKSPACE_SECRET
```

Keep the secret out of browser code and public environment variables. During a production build, the plugin registers a release and bakes its release token into the browser bundle. Source maps are handled automatically. Choose a stable service name in the build configuration; it defaults to the unscoped `package.json` name. Use the same name for build and server telemetry.

  </Step>
  <Step title="Connect your build">

Add `interfere()` to your Vite plugins. Keep your other plugins and app configuration.

```ts vite.config.ts
import { interfere } from "@interfere/vite/plugin";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), interfere({ serviceName: "storefront" })],
});
```

The plugin uploads source maps and registers the build's release. See [Releases and source maps](/sdk/releases) for custom build environments.

  </Step>
  <Step title="Initialize and wrap your app">

Call `init()` in your browser entry point, before React renders.

```tsx src/main.tsx
import { init } from "@interfere/vite/init";
import { InterfereProvider } from "@interfere/vite/provider";
import { createRoot } from "react-dom/client";
import App from "./App";

init();

createRoot(document.getElementById("root")!).render(
  <InterfereProvider>
    <App />
  </InterfereProvider>,
);
```

Set [consent during initialization](/sdk/consent) if capture must wait for a visitor’s choice. Review [replay masking](/sdk/replay-privacy) before recording customer sessions.

  </Step>
</Steps>

## Verify capture

Verify the production build artifact. This setup does not promise token minting from the development server.

Build and deploy to staging, then report a test error from an existing button or event handler in your staging app:

```ts
import { capture } from "@interfere/vite/init";

capture(new Error("Interfere setup test"));
```

Open [Services](/product/services) and select the service to confirm that traffic arrives, then remove the test call.

<Note>
  Legacy `VITE_INTERFERE_PUBLIC_KEY` configuration is deprecated. SDK 13.0.x production builds use
  the release token baked by the plugin.
</Note>
